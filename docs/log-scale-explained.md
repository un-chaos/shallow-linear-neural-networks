# 对数坐标入门（为什么我一开始不建议用，以及什么时候该用）

这份说明是为「不想用对数坐标、但也不确定为什么」的情况写的。结论先说：

- **坐标轴**用对数，会改变图形形状，读起来需要换算；
- **颜色**用对数，不改变任何数据，只是让跨度大的数值都能被看见。

这个项目里的相图，**坐标轴（N、P）一直是线性的**，只有颜色可选对数。

---

## 1. 普通坐标（线性坐标）

普通坐标就是等距刻度：0、10、20、30……每格代表同样的增量。

它的好处是**眼睛读到的距离就是数值差**。坏处是：**大数会把小数彻底压没**。

例子：假设有四个 loss

| 实验 | loss |
| --- | --- |
| A | 0.7 |
| B | 0.1 |
| C | 0.005 |
| D | 0.0001 |

在 0 ~ 0.7 的线性坐标上画：

```
0.7 |█ A
0.6 |
0.5 |
0.4 |
0.3 |
0.2 |
0.1 |█ B
0.0 |▏C D      <- C 和 D 几乎贴在 0 上，完全分不出谁是谁
```

C 和 D 差了 **50 倍**，但图上都是"一条线"。

---

## 2. 对数坐标

对数坐标**不是等距，而是等比例**：每往上走相同的一段，代表**乘同一个倍数**（通常是 10 倍）。

`log10` 的含义是"10 的几次方"：

| 数值 | log10 | 读作 |
| --- | --- | --- |
| 1 | 0 | 10 的 0 次方 |
| 10 | 1 | 10 的 1 次方 |
| 100 | 2 | 10 的 2 次方 |
| 0.1 | −1 | 10 的 −1 次方 |
| 0.001 | −3 | 10 的 −3 次方 |

同样这四个 loss，改用对数坐标：

```
0.7  |█ A          10^0
0.1  |█ B          10^-1
0.01 |
0.005|█ C          10^-3
1e-4 |█ D          10^-4
```

现在 A、B、C、D 都看得见了。**代价**：图上的"距离"不再等于数值差。
B 到 C 的间距看起来和 C 到 D 差不多，但实际差距是 20 倍和 50 倍，只是"倍数"相近。

### 什么信号该用对数坐标

- 数值**跨好几个数量级**（比如从 0.0001 到 1，跨 4 个数量级）；
- 你关心的是**倍数关系**（"降了一个数量级"、"慢了多少倍"）；
- 数值是**乘性增长**的（指数衰减、幂律）。

### 什么信号别用

- 数值范围本来就小（比如 0 到 1 全部挤在一起）；
- 你关心的是**绝对差值**（"少了 0.3"）；
- 数值可能**等于或小于 0**——`log(0)` 是负无穷，对数坐标画不出来。
  这也是为什么 `train loss`（在 `P<N` 时会变成 `1e-35`，而且理论上可以到 0）
  不适合对数坐标。

---

## 3. 坐标轴的对数 vs 颜色的对数

这是最容易混的一点。两者完全独立：

| | 改的是什么 | 影响 |
| --- | --- | --- |
| 坐标轴取对数 | 位置的映射 | 图的**形状**变了，斜率、曲线弯曲程度都变 |
| 颜色取对数 | 数值→颜色的映射 | 图的**形状不变**，只是颜色对比度变化 |

热力图（相图）的坐标轴是格子位置，本来就该线性；而颜色要覆盖 4 个数量级的 loss，
所以这个项目里：

- **坐标轴：永远线性**（按你的要求）；
- **颜色：可选**，交互图上可以直接切换 linear / log / asinh 三种，亲眼对比区别。

`asinh` 是折中方案：它在 0 附近接近线性（所以能处理 0 和负数），在大数处接近对数，
不会像 `log` 那样把极小值压成一条。想理解 `log` 的效果，就在交互图上切换着看。

---

## 4. 在自己数据上试

交互图 `interactive.html` 打开后：

1. 顶部「颜色刻度」选 `linear`，观察：低 loss 区域全变成同一个颜色，看不出差别；
2. 切成 `log`，同一份数据，低 loss 区域的层次立刻出来了——**数据一个字节都没变**，
   变的只是"数值怎么映射到颜色"。

这就是对数刻度唯一的用途：**把跨数量级的数据塞进同一张图**。
它不会凭空创造信息，也不改变任何数值。
